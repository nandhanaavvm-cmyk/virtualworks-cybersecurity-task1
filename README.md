# Password Strength Checker

A Python command-line tool that evaluates password strength based on core cybersecurity criteria and provides actionable improvement feedback.

## Features
- **Length Verification:** Checks for a minimum of 8 characters (awards bonus points for 12+ characters).
- **Character Variety:** Validates the presence of uppercase letters, lowercase letters, digits, and special symbols.
- **Strength Classification:** Categorizes passwords into *Weak*, *Moderate*, *Strong*, or *Very Strong*.
- **Actionable Feedback:** Lists missing criteria to help users strengthen weak passwords.

## How to Run
1. Ensure Python 3 is installed on your system.
2. Run the script in your terminal:
   ```bash
   python password_checker.py
